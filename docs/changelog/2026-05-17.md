# Changelog técnico 2026-05-17

## Contexto
Implementación del nuevo diseño profesional generado en Stitch ("Furvoley CRM Pro v2", design system "Elite Club Operations") sobre el panel admin (`CrmApp.tsx`), conectado a datos reales y manteniendo toda la funcionalidad existente (RBAC, notificaciones, navegación, signOut, export CSV).

## Cambios
- Se modificó:
  - `src/components/crm/crm-vars.css` → paleta y tokens "Elite Club Operations" (sidebar slate, accent `#004ac6`, surfaces, status colors, sombras).
  - `src/components/crm/CrmApp.tsx`:
    - `Sidebar` rediseñado a 280px con brand "Furvoley / SISTEMA DE GESTIÓN", nav con borde activo azul, bloque user inferior con avatar y rol, botón logout con hover rojo.
    - `KPICard` rediseñado con icon pill arriba-izq + trend/status pill arriba-der + label uppercase + número 30px + sub + mini line chart al pie. Soporta nuevo prop `badge` (`{ kind: 'success'|'warning'|'danger'|'info', text, icon? }`).
    - `Dashboard` rehecho como bento grid: 4 KPIs (auto-fit minmax 240px) + chart 2fr / donut 1fr + eventos 5fr / cobros 7fr. Donut con total y % en leyenda. Filas con padding 16x32. CTAs "Ver calendario" y "Gestionar pagos" enlazadas a `setActive`.
    - `TopBar` rehecho como sticky 72px con título de sección + fecha capitalizada en es-ES; cluster derecho con botón "Exportar" (sólo dashboard/ADMIN), bell circular con badge unread, y bloque user con gradiente azul corporativo.
    - Wrapper externo migra `bg-[#F8F7F5]` → `var(--surface)`. Loading overlay actualizado a tonos coherentes con surface.
    - Eliminada variable `dateStr` no usada (la fecha ahora vive en TopBar como `topDateStr`).
- Se creó:
  - `docs/project-index.md`, `docs/maps/crm-admin.md`, `docs/design/crm-elite-club-operations.md`, `docs/changelog/2026-05-17.md`.
  - `stitch-pro-v2-dashboard.html` (artifact del mockup generado, referencia visual).

## Impacto funcional
- El admin del CRM ahora ve un panel con identidad B2B/SaaS coherente: sidebar oscuro, accent azul corporativo, tarjetas con generous whitespace y filas de tabla con altura cómoda.
- Las CTAs del bento llevan a las pantallas correctas (`calendario`, `contabilidad`) usando la navegación interna existente.
- El botón "Exportar" sigue descargando el CSV de facturas (`/api/billing/reports/invoices-csv`).
- Notificaciones y signOut funcionan igual; no se tocó la lógica.
- Member panel (rol `MEMBER`) no se ve afectado: `AppShell` sigue renderizando `MemberShell`.

## Impacto técnico
- Cambio global de la paleta CSS: cualquier componente del CRM que usara `var(--accent)`, `var(--border)`, etc. se ve afectado automáticamente (sólo es color, no estructura).
- `CrmApp.tsx` sigue con `@ts-nocheck`; no se introducen errores de tipo (verificado con `tsc --noEmit`).
- No se modificaron rutas, endpoints ni Prisma schema.
